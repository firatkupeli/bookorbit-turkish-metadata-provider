# Third-party material

`tools/conformance/main.go` is an unmodified copy from
[bookorbit/bookorbit-metadata-providers](https://github.com/bookorbit/bookorbit-metadata-providers/tree/30a5ef4aca62beb93561fac8333d0a926a77e365/conformance),
commit `30a5ef4aca62beb93561fac8333d0a926a77e365`. Its MIT license is preserved
in `tools/conformance/LICENSE`.

Moly and LubimyCzytac implementations were read for design reference; their application
code has not been copied. No BookOrbit AGPL application code is bundled here.

`tests/fixtures` contains reduced fragments of public Kitapyurdu HTML retrieved
on 2026-11-27. Reviews, account information, tracking tokens, executable scripts and most page
content were removed; the book description is shortened. These fragments illustrate
the parser's input format; Kitapyurdu and publishers retain rights in their content.
The project's MIT license does not license third-party metadata or cover artwork.
